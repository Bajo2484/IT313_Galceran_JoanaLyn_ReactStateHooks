# IT313 Laboratory 5 - React State & Hooks

## Problem Lab Timer and Practice Tracker is a small React Native application that helps students track solved practice problems and laboratory practice time. ## Approach The application uses useState for state management, useEffect and setInterval for the stopwatch, clearInterval for cleanup, conditional rendering for messages and status, event handling for the buttons, lifting state up through LabScreen, and a custom useStopwatch hook.

## How to Run

1.  Open the project in VS Code.
2.  Install the dependencies.
3.  Run npx expo start.
4.  Open the project using Expo Go.
